# MySQL Exercises Repository

**Italiano:**
Raccolta completa degli esercizi e database su **MySQL** sviluppati durante il percorso Boolean, strutturata in moduli tematici indipendenti. Ogni cartella di esercizio è provvista di file `.sql` per la definizione della struttura dei dati (DDL), inserimento record e query specifiche (DML/DQL).

---

## Moduli & Contenuti

| Modulo | Descrizione | File SQL | Link |
| :--- | :--- | :--- | :--- |
| **mysql-intro** | Concetti base di MySQL: creazione di database, tabelle e prime interrogazioni. Il modulo copre numerosi use-case reali (prodotti, spedizioni, studenti, inventario, voli, recensioni, ecc.). | 15 File | [Apri mysql-intro](./mysql-intro) |

---

## Come eseguire gli script

1. Assicurati di avere un server MySQL attivo (es. tramite XAMPP, MAMP o MySQL Workbench).
2. Entra nella cartella di un modulo (es. `cd mysql-intro`).
3. Importa o esegui i file `.sql` nel tuo client preferito, oppure esegui da terminale: `mysql -u root -p < nome_file.sql`.

## How to Run the Scripts

1. Ensure you have an active MySQL server (e.g., via XAMPP, MAMP, or MySQL Workbench).
2. Navigate to a module folder (e.g., `cd mysql-intro`).
3. Import or execute the `.sql` files in your preferred client, or run from terminal: `mysql -u root -p < file_name.sql`.
